# React Results App

Student results app built for the BCG technical test.

| Folder | Stack |
|---|---|
| [frontend](frontend) | React 17, Material UI, Formik + Yup, Chart.js |
| [backend](backend) | Node.js, Express, MongoDB, OData, Excel import |

## Run locally

```bash
# backend (needs MongoDB on localhost:27017, see backend/config.json)
cd backend && npm install && npm run start:dev

# frontend
cd frontend && npm install && npm start
```
